# Task detail index

`implementation-plan.md` remains the high-level outline. The files in this folder contain the detailed execution contract for each task.

Execution rule after plan approval:

- Work exactly one task at a time.
- Validate the task before reporting completion.
- Update `docs/implementation-plan/progress.md` with work completed, validation, decisions, deviations, lessons, and newly discovered risks.
- Stop after each task and wait for instruction before starting the next one.
